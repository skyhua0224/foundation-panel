# Moonlight Streaming Shortcuts

## 🖥️ PC Client (Windows / macOS / Linux)

### Session control

- `Ctrl+Alt+Shift+Q` - Quit the streaming session (the host game keeps running)
- `Ctrl+Alt+Shift+D` - Minimize the streaming window
- `Ctrl+Alt+Shift+X` - Toggle full screen / windowed mode
- `Ctrl+Alt+Shift+S` - Show the performance statistics overlay

> 💡 Performance statistics are not supported on Steam Link or Raspberry Pi

### Mouse control

- `Ctrl+Alt+Shift+Z` - Toggle mouse and keyboard capture
- `Ctrl+Alt+Shift+M` - Toggle mouse mode (pointer capture / direct control)
- `Ctrl+Alt+Shift+C` - Toggle the local cursor in remote desktop mode
- `Ctrl+Alt+Shift+L` - Lock the mouse pointer to the video area

> 💡 Locking the mouse requires the "Optimize mouse for remote desktop" option

### Other functions

- `Ctrl+Alt+Shift+V` - Type the clipboard text on the host

## 📱 Android Client

### Touchpad mode

- `One finger tap and drag` - Move the mouse cursor
- `One finger tap` - Left mouse click
- `One finger long press` - Right mouse click
- `Two finger vertical drag` - Mouse wheel scroll
- `Three finger tap` - Show the virtual keyboard

### Touchscreen mode

- `Tap a position` - Move the cursor there and left click
- `Long press a position` - Right click there
- `Tap and drag` - Click and drag
- `Three finger tap` - Show the virtual keyboard
- `Two finger pinch` - Zoom (iOS only)
- `Two finger drag` - Pan (iOS only)

### Gamepad as mouse

- `Hold Start` - Turn mouse emulation on or off
- `Stick` - Move the mouse cursor
- `A button` - Left mouse button
- `B button` - Right mouse button

### Special combinations (gamepads with missing buttons)

- `R1+Start` - Emulate the Select button
- `Start+Select` - Emulate the Mode button (gamepads with a Select button)

> 💡 Android supports Xbox 360/One, PS3/PS4 and other gamepads, but some gamepads connected over Bluetooth may have latency or disconnection problems

## 🍎 iOS / tvOS Client

### iOS gestures

- `Swipe right from the left edge` - Disconnect the stream
- `Three finger tap` - Show the virtual keyboard

### tvOS controls

- `Double press Menu` - Disconnect the stream (Apple TV)
- `Apple TV remote touchpad` - Move the mouse and click

### Gamepad support

> 💡 iOS 13+ / tvOS 13+ support Xbox One S and PS4 gamepads over Bluetooth, with every physical button (Select, L3, R3). iOS/tvOS 14+ support gamepad rumble.

> 📱 iPadOS 13.4+ supports mouse input, with limits. iPadOS 14+ improves mouse support, but non-Apple mice work best over USB rather than Bluetooth.
