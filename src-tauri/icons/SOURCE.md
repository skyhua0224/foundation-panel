# Icon files

- Sun (tray icons, generated): tray/sunshine.ico, tray/sunshine-playing.ico, tray/sunshine-pausing.ico, tray/sunshine-locked.ico (every size of them), and src/assets/favicon.ico (browser favicon of the Panel home page: 16, 32, 48).
- Vivi (unchanged art): icon.ico (app, taskbar, shortcuts: every size), the 32x32.png, 128x128.png and 128x128@2x.png cut out of icon.ico by the generator (--panel-vivi-png), and src/assets/sunshine.ico and installer-ui/icons/icon.png outside this directory.
- Which art goes where (owner rule 2026-11-09): the cloudless sun (foundation-ui src/assets/app/app-icon.svg; source and permission in that directory SOURCE.md: SunshineQ, file 素材/无云.svg, permission of AlkaidLab in the group chat 2026-11-08) is used ONLY for the smallest icons: the tray icons with their play / pause / lock badge variants, the browser favicon, and the title-bar glyph in the app. Everything else is Vivi (the character art; sources: foundation-ui src/assets/vivi, built by scripts/build-vivi-assets.py). The sun files are generated by foundation-ui tools/app-icons/gen.py; sizes up to 32 px come from a hinted copy of the SVG (thicker outline, eyes, mouth) and the badges are drawn by the generator. Not for use outside the products. ICO files: 256 px entry PNG, smaller ones 32-bit BMP.
- Windows resources compile in the Windows build; the files were checked here (sizes, entries), not in a built exe.
